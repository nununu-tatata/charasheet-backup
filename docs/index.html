はじめかた

パソコンでの操作をおすすめします。

  1. スプレッドシートをコピーする

    上の「スプレッドシートをコピーして使う」ボタンを押し、出てきた画面で「コピーを作成」を押します。

  2. URLを貼り付ける

    「コンバートURL入力」シートの B2セル から下に、キャラクター保管所のキャラシURLを1行に1つずつ貼り付けます。

    💡 キャラがたくさんあるときは

    キャラクター保管所のマイリストから、全キャラのURLをまとめてコピーできます。1つずつコピーする必要はありません。

    やり方は、下の「マイリストからURLをまとめて取得」か、スプレッドシートのメニュー 📥 コンバート → マイリストからURLをまとめて取得する方法 で確認できます。

    🔖 まとめて取得する方法を見る

  3. コンバートを実行する

    上のメニューの 📥 コンバート → URLからコンバート を押します。

    ※メニューが出ていない場合は、ページを再読み込みして少し待ってください。

  4. 初回だけ：Googleの許可画面に答える

    はじめて実行すると「承認が必要です」と表示されます。次の順に進めてください。

    1. 「続行」を押し、自分のGoogleアカウントを選ぶ
    2. 「このアプリは Google で確認されていません」と出たら、左下の「詳細」を押す
    3. いちばん下の「保管所⇒スプシバックアップ（安全ではないページ）に移動」を押す
    4. アクセスを許可する項目の画面が出たら、いちばん上の「すべて選択」にチェックを入れてから「続行」を押す
    「すべて選択」にチェックを入れずに進むと、許可が足りずにコンバートできません。うまく動かないときは、もう一度実行して許可し直してください。
    この警告は、個人が作ったツールにはいつも表示されるものです。
    このツールが行うのは「スプレッドシートの読み書き」と「キャラクター保管所からのデータ取得」だけで、データが外部に送られることはありません。

    許可したら、もう一度 URLからコンバート を押してください。

Googleの制限で、1回の実行は6分までです。キャラが多いときは途中で止まりますが、もう一度実行すれば続きから処理されます。（目安：1回で約50キャラ）

キャラシを更新したとき

  1. 全キャラまとめて更新

    📥 コンバート → 全シートを一括更新 を押すと、「シート一覧」に載っている全キャラを確認し、キャラクター保管所で変更があったキャラだけを更新します。

    ※一度コンバートしたキャラは、自動で「シート一覧」に追加されています。

  2. 特定のキャラだけ更新

    そのキャラのURLを「コンバートURL入力」に貼り付けて URLからコンバート を押します。同じキャラのシートが新しい内容に置き換わります。

新しいバージョンが出たら

不具合の修正や機能の追加をしたときは、新しいバージョンとして公開します。コピー済みのスプレッドシートは自動では新しくならないので、次の手順で乗り換えてください。

  1. 新しいバージョンが出たか確認する

    次のどれかで確認できます。

    • コンバートや一括更新が終わったときのメッセージに「🆕 新しいバージョン（v〇.〇.〇）が公開されています」と表示される
    • メニューの 📥 コンバート → バージョン情報・更新の確認 を押す
    • このページ上部の「最新版」の番号と見比べる（変更内容は、ページ下の最終更新日を押すと見られます）

  2. 新しいスプレッドシートをコピーする

    このページの「スプレッドシートをコピーして使う」から、もう一度コピーします。はじめて使うときと同じく、初回だけGoogleの許可画面が出ます。

  3. 古いスプレッドシートからキャラを移す

    1. 古いスプレッドシートを開き、ブラウザのアドレス欄のURLをコピーする
    2. 新しいスプレッドシートで、メニューの 📥 コンバート → 古いスプレッドシートから引っ越す を押す
    3. 出てきた入力欄に、古いスプレッドシートのURLを貼り付けて「OK」を押す（全キャラのURLが「コンバートURL入力」に移ります。古いスプレッドシートは変更されません）
    4. URLからコンバート を押す（キャラが多いときは、何回か実行すると続きから処理されます）
    メニューに「古いスプレッドシートから引っ越す」がないときは（手作業で移す方法）
    1. 古いスプレッドシートの「シート一覧」シートを開く
    2. B2セルを選び、Ctrl + Shift + ↓（Macは ⌘ + Shift + ↓）でURLの一番下まで選んでコピーする
    3. 新しいスプレッドシートの「コンバートURL入力」シートの B2セル に貼り付ける

  4. 古いスプレッドシートを片付ける

    新しい方で全キャラ移せたことを確認したら、古いスプレッドシートは削除してかまいません。念のためしばらく残しておいても大丈夫です。

キャラのシートに自分で書き込んだメモや、変更した設定（チャパレの設定など）は、新しいスプレッドシートには移りません。必要なものは、古いスプレッドシートから控えておいてください。

マイリストからURLをまとめて取得

キャラクター保管所のマイリストにある全キャラのURLを、ボタン一つでコピーできます。（パソコンのブラウザ向け）

  1. 最初に一度だけ：ブックマークに登録

    ブックマークバーを表示します。（Ctrl + Shift + B、Macは ⌘ + Shift + B）

    下の青いボタンを、マウスでつかんでブックマークバーまでドラッグします。

    キャラシURL抽出

    ドラッグで登録できないときは
    1. 下の「コードをコピー」を押します。
    2. ブックマークバーで右クリック →「ページを追加」（ブラウザによっては「ブックマークを追加」）を選びます。
    3. 名前に「キャラシURL抽出」、URL欄にコピーしたコードを貼り付けて保存します。

  2. マイリストで実行する

    キャラクター保管所にログインして、マイリストを開きます。

    ブックマークバーの「キャラシURL抽出」を押すと、全ページを読み込んでURLの一覧が出てきます。

  3. スプレッドシートに貼り付ける

    「コピーする」を押し、「コンバートURL入力」シートの B2セル を選んで貼り付けます。あとは URLからコンバート を押すだけです。

不要になったら：ブックマークバーの「キャラシURL抽出」を右クリックして「削除」を選ぶと消せます。
このブックマークは、マイリストを開いて押したときだけ動きます。他のページで勝手に動いたり、情報を外部に送ったりすることはありません。

よくある質問

途中で止まってしまいました

Googleの制限で、1回の実行は6分までです。もう一度同じメニューを実行すると続きから処理されます。

「URLからコンバート」では、終わったURLは入力欄から自動で消え、残っているものだけが次に処理されます。

「今日はこれ以上キャラシを取得できません」「urlfetch を実行した回数が多すぎます」と表示されました

原因：このツールはGAS（Google Apps Script）という仕組みで動いています。GASには、Googleが定めた「外部サイトからデータを取得できる回数」の上限があり、個人のGoogleアカウントでは1日あたり約20,000回です。その上限に達すると、このメッセージが表示されます。

このツールだけで上限に達することはほとんどありません。このツールがデータを取得するのは1キャラにつき1回だけなので、100キャラをコンバートしても約100回です。

他のGASツールを使っている場合は注意：上限は「スプレッドシートごと」ではなく「Googleアカウントごと」に数えられます。同じアカウントで、外部サイトとやり取りする他のGASツールを使っていると、その回数も合算されます。自動で何度も実行されるツールの場合、それだけで上限近くまで使っていることがあります。

対処法：

  • 時間をおいて（目安：24時間後）もう一度実行してください。処理できなかったURLは入力欄に残っているので、続きから処理されます。
  • すぐに使いたい場合は、他のGASツールを使っていない別のGoogleアカウントでスプレッドシートをコピーして使う方法もあります。
「セル数が上限を超えます」と表示されて、コンバートできません

原因：Googleスプレッドシートは、1つのファイルに入るセルの数が全部で1,000万セルまでと決まっています。このツールは1キャラにつき1枚のシートを作るので、キャラがとても多いと上限に届きます。

入るキャラ数の目安：最新のスプレッドシートでは約1,900キャラまで入ります。公開日（2026年10月22日）にコピーしたスプレッドシートは、キャラ用のシートが大きく作られている場合があり、その場合は約350キャラが目安です。

※どちらか分からないときは、「テンプレート」シートの一番下の行番号を見てください。1000行以上あれば、大きく作られている方です。

対処法：

  • 「新しいバージョンが出たら」と同じ手順で、新しいスプレッドシートに乗り換えてください。古いスプレッドシートを使っていた場合は、それだけで入るキャラ数が大きく増えます。
  • それでも足りない場合は、スプレッドシートを2つに分けて使ってください（例：PC用とNPC用、卓ごとなど）。
  • 使わなくなったキャラのシートを削除すると、その分の空きができます。
URLが「m」から始まる長い形になっています

そのままで大丈夫です。キャラシの名前から開くと …/m36aedc6… のような形になりますが、自動で数字の形（…/5219700）に直して保存します。

7版や他のシステムのキャラシは使えますか？

現在はクトゥルフ神話TRPG 6版のキャラシのみ対応しています。他のシステムのURLはエラーとしてスキップされます。

新しいバージョンが出たら、どうすればいいですか？

新しい版が出ると、コンバート完了時のメッセージでお知らせします。（バージョン情報・更新の確認 からも確認できます）

乗り換え方は「新しいバージョンが出たら」で詳しく説明しています。新しいスプレッドシートのメニュー 古いスプレッドシートから引っ越す に古いスプレッドシートのURLを貼れば、全キャラのURLをまとめて移せます。

スマホでも使えますか？

スマホのスプレッドシートアプリでは、メニューのボタンが使えません。コンバートや更新はパソコンで行ってください。保存したシートを見るだけならスマホでもできます。

非公開にしているキャラシも保存できますか？

非公開マイリストに入れているキャラシは、保存できません。

非公開のキャラシは、キャラクター保管所にログインしている本人しか見られません。このツールはログインせずにキャラシを取得するため、非公開のキャラシを読み込めません。コンバートすると「キャラシが見つかりません（非公開設定か、削除された可能性があります）」と表示されます。

また、マイリストからURLをまとめて取得する機能でも、非公開マイリストのキャラシは対象外です。

保存したい場合は、キャラクター保管所でキャラシを公開に切り替えてからコンバートしてください。
